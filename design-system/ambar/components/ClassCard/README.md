La ficha de una clase: segunda lámina, o bloque de clase en web. Tú das el beneficio (titular de dos líneas), tres datos (zona, impacto, calor), una descripción de tres o cuatro líneas y la frase de "Es para ti si".

- Foto arriba fundida a `negro`; texto alineado a la izquierda.
- Orden fijo: `titular`, fila de datos en `versalitas`, línea de 1px, `cuerpo-mayus` justificado, `etiqueta-roja`, `cuerpo`.
- El botón es opcional y va al final, centrado.
